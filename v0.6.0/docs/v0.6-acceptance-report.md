## New Trajectory Features

- `TrajectoryState` with phases: IDLE, UNDERSTAND, INSPECT, DIAGNOSE, PLAN, IMPLEMENT, TEST, VERIFY, DONE, BLOCKED
- `EvidenceLedger`
- `TrajectoryController` pure core
- Guarded mode default, strict/off available
- Fast path for trivial tasks
- Tool blocking for edit/write in non-implementation phases
- Compaction snapshot includes trajectory
- `/dsh-trajectory`, `/dsh-phase`, `/dsh-trajectory-mode`
- `/dsh-status` now shows route + phase + mode + next + evidence counts

## Known Limitations

- `bash` cannot be reliably classified as read-only vs mutating; we do not fake hard enforcement.
- Tool gating is name-based for `edit`/`write`; `bash` is guided but not blocked.
- Trajectory transitions are evidence-based heuristics, not a full workflow engine.
