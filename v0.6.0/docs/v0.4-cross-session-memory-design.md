# Pi 版 v0.4 — 跨会话记忆检索与召回设计

> 本文件为 v0.4 设计，基于 v0.3 会话记忆实现。

## 1. 研究参考

- `agent-knowledge`：跨会话知识库、混合检索、wakeup 注入、session search。
- `pi-topic-memory`：per-session topic 匹配与注入。
- `cavemem`：跨 agent 持久记忆、压缩存储、快速检索。

## 2. 目标

- 在 v0.3 的 session 记忆基础上，支持跨会话检索。
- 新会话/当前会话能召回同一 workspace 历史会话中的相关决策、设计、错误。
- 注入时区分“当前会话记忆”和“历史会话记忆”。

## 3. 非目标

- 不引入外部向量数据库。
- 不做语义嵌入（留到后续）。
- 不做跨机器同步。

## 4. 架构

```text
MemoryStore
  ├─ sessions: { [sessionId]: SessionMemory }
  └─ searchMemory(store, workspace, query, limit)
        ├─ 遍历同 workspace 的 sessions
        ├─ 对 topic.title / decisions / designs / errors / todos 打分
        └─ 返回 Top-K MemoryEntry

before_agent_start
  ├─ 当前 session memory snapshot
  └─ 历史会话 recall（跨 session Top-K）
```

## 5. 检索算法

对每个候选 entry：

```text
score = dice(query, entry.content) * 0.5
      + dice(query, topic.title) * 0.3
      + recencyBoost * 0.2
```

- `recencyBoost` 基于 `createdAt` 衰减。
- 同 session 当前条目不重复注入。
- 默认 `topK = 3`，`minScore = 0.25`。

## 6. 命令

| 命令 | 作用 |
|---|---|
| `/dsh-memory-search <query>` | 跨会话搜索记忆 |
| `/dsh-memory-recall <query>` | 手动触发历史记忆召回 |
